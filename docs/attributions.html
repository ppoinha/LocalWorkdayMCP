Its tool definitions are derived from the OpenAPI descriptions of those interfaces that Workday publishes to its customers. The interfaces and descriptions remain the property of Workday, Inc.

Model Context Protocol

DaySight MCP implements the Model Context Protocol (MCP), an open standard for connecting AI assistants to tools and data, using the official TypeScript SDK (@modelcontextprotocol/sdk, MIT licence).
