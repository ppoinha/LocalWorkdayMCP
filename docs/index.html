Claude Desktop extension for Workday

Ask Claude about your Workday data in plain English.

Workday MCP connects Claude to the Workday REST API. You sign in as yourself, so Claude sees what you are allowed to see, and nothing more.

Tools that change data in Workday stay hidden until you switch them on. Start by looking, and decide later whether you want more.

How it works

From download to first answer in four steps

  1. Register your API Client

    In Workday, you create your own API Client and choose its scopes. Your client ID and secret are yours alone.

  2. Install the extension

    In Claude Desktop, open Settings, Extensions, Advanced settings and pick the downloaded file.

  3. Fill in the short form

    Paste your client details and endpoints. Leave "Allow changes in Workday" off.

  4. Sign in and ask

    Ask Claude to call workday_login, approve in your browser, then start asking questions.
