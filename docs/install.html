Install

Set up in a few steps

You register your own Workday API Client, install one file in Claude Desktop and sign in. Nothing is shared with anyone else.

What you need

1

Windows and Claude Desktop

A current version of Claude Desktop with you signed in. For privacy and safety, use Claude Enterprise, which does not use your conversations to train models.

2

Your own Workday API Client

You register it in Workday and get your own client ID and secret. Ask your Workday administrator if you lack the permission.

3

Port 3000 free

The sign-in callback listens on your PC at https://localhost:3000/callback while you log in.

4

A browser

The Workday sign-in page opens there and sends you back to your own computer.

The steps

  1. Register your API Client

    In Workday, register an API Client for Integrations with the scopes for the areas you want. Keep its client ID, secret and endpoints. The guide covers each Workday screen.

  2. Download the file

    Get daysight-mcp-<version>.mcpb from the Releases page, under Assets.

  3. Install in Claude Desktop

    Open Settings, Extensions, Advanced settings, Install Extension and pick the file. Use this route rather than double-clicking the file.

  4. Fill in the form

    Enter your client ID, secret, authorization and token endpoints. Keep the default redirect address and switch on Allow Workday Query Language (WQL) reports for workforce analytics.

  5. Sign in

    In a new chat in the Chat tab, ask your assistant to call workday_login. Sign in to Workday as yourself and approve. Your browser warns once about the local certificate; continue to localhost.

  6. Ask a question

    Try "Show the board scorecard", then "Draw it as a dashboard". Ask for workday_auth_status any time to check that you are signed in.

Good to know

  • Use the Chat tab of Claude Desktop. The extension's tools do not load in the Code tab.
  • After changing a setting, restart Claude Desktop and start a new chat.
  • Try it on a sandbox or implementation tenant first.
  • Give your API Client only the scopes that match the questions you want to ask.
  • Whatever your assistant retrieves is sent to the AI provider as part of the conversation. Use Claude Enterprise, which does not use your conversations to train models, and check your company's policy on HR data first.

30-day trial and licence key

The download works for 30 days for each Workday tenant, counted from the first time you use it. When the trial ends, your assistant says so and shows a request code (it is a hash, not your tenant name). To continue, email us your request code and you receive a licence key. Paste it into the Licence key setting of the extension, quit and reopen Claude Desktop and start a new chat. Nothing in Workday is changed when the trial ends, and the trial check sends nothing off your computer.
