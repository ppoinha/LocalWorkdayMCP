Install

Set up in a few steps

Your HRIS administrator registers a Workday API Client and gives you its details. You install DaySight MCP in Claude Desktop or in the ChatGPT desktop app and sign in with your own Workday account.

What you need

1

Windows and your AI app

The Claude Desktop app or the ChatGPT desktop app, with you signed in. ChatGPT in the browser cannot use a local server. For privacy and safety, use Claude Enterprise or ChatGPT Enterprise with data sharing and model training turned off.

2

A Workday API Client

Your HRIS administrator registers it in Workday and gives you the client ID, the endpoints, the callback port and the scopes. With PKCE there is no client secret.

3

The callback port

The sign-in callback listens on your PC at https://localhost:3000/callback while you log in. The port is the one your HRIS administrator used for the API Client (3000 by default): enter the same one in the app, and keep it free while you sign in.

4

A browser

The Workday sign-in page opens there and sends you back to your own computer.

Install in Claude Desktop

  1. Get the API Client details

    Your HRIS administrator runs the Workday task Register API Client: Authorization Code Grant with Support PKCE ticked, so no client secret is needed. They choose the scopes and give you the client ID and endpoints. The PDF guide covers each Workday screen for them.

  2. Download the file

    Download daysight-mcp-0.10.0.mcpb (about 0.8 MB). It contains no secrets. You can check it against the SHA-256 value below.

  3. Install in Claude Desktop

    Open Settings, Extensions, Advanced settings, Install Extension and pick the file. Use this route rather than double-clicking the file.

  4. Fill in the form

    Enter your client ID, the authorization and token endpoints, and tick Use PKCE (no secret needed). Keep the default redirect address.

  5. Sign in

    In a new chat in the Chat tab, ask your assistant to call workday_login. Sign in to Workday as yourself and approve. Your browser warns once about the local certificate; continue to localhost.

  6. Ask a question

    Try "Show the board scorecard", then "Draw it as a dashboard". Ask for workday_auth_status any time to check that you are signed in.

Install in the ChatGPT desktop app

A Windows setup program asks for your Workday API Client details and adds DaySight MCP to the app. You do not need Node.js or a command window.

  1. Get the API Client details

    The same details as for Claude Desktop: client ID, endpoints, callback port and scopes from your HRIS administrator. With PKCE there is no client secret.

  2. Download the setup

    Download DaySightMCP-Setup-0.10.0.exe (about 90 MB, Windows). Check it against the SHA-256 value below. The setup is signed with DaySight's own certificate, which Windows does not know, so it may say “unknown publisher”.

  3. Run the setup

    Close the ChatGPT desktop app and run the file. Enter your client ID and the authorization and token endpoints, then the callback port and the scopes you were given. Leave the client secret empty. Click Install.

  4. Restart ChatGPT

    Quit the app completely, reopen it and start a new chat. In Settings, Plugins, MCPs you should see daysight under Servers, switched on.

  5. Sign in and ask

    Ask the app to call workday_login, sign in to Workday as yourself and approve. Then try "Show the board scorecard". To change a setting later, run the setup again.

The ChatGPT desktop app sends tool results to OpenAI. For privacy and safety, use ChatGPT Enterprise with data sharing and model training turned off, and check your company's policy on HR data first. Check with your workspace administrator that local MCP servers are allowed in your plan.

Good to know

  • Use the Chat tab of Claude Desktop. The extension's tools do not load in the Code tab.
  • After changing a setting, restart Claude Desktop or the ChatGPT desktop app and start a new chat.
  • Try it on a sandbox or implementation tenant first.
  • The API Client should only have the scopes that match the questions people want to ask.
  • Whatever your assistant retrieves is sent to the AI provider as part of the conversation. Use Claude Enterprise or ChatGPT Enterprise with data sharing and model training turned off (both providers say that business data is not used for training by default), and check your company's policy on HR data first.
  • Claude Desktop and the ChatGPT desktop app share your sign-in folder. Use one at a time, and give both the same callback port, or ask your administrator for a second API Client.

30-day trial and licence key

The download works for 30 days for each Workday tenant, counted from the first time you use it. When the trial ends, your assistant says so and shows a request code (it is a hash, not your tenant name). To continue, email us your request code and you receive a licence key. Paste it into the Licence key setting of the extension, quit and reopen Claude Desktop and start a new chat. Nothing in Workday is changed when the trial ends, and the trial check sends nothing off your computer. In the ChatGPT desktop app, run the setup again and enter the key on the Tool approvals page.
